Projeto realizado por: Julio Cesar Nardi
Curso: Ciências da Computação - 5º Fase - UNOESC Campus Videira

Descrição:

Este projeto é nada mais que um sistema simples de PHP para uma simulação de cadastro e login de usuários, sem a necessidade de um banco de dados.
É um projeto feito com a utilização de cookies e permite que os usuários se cadastrem com um e-mail e façam um login para o dashboard com o mesmo.


Como executar:
Rodar index.php
